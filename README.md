# 杂念系统（astrbot_plugin_idle_mind）

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![AstrBot](https://img.shields.io/badge/AstrBot-%3E%3D4.17.0-blue.svg)](https://astrbot.app)
[![version](https://img.shields.io/badge/version-1.0.0-orange.svg)](metadata.yaml)

让它像人一样「想」，而不是「每次都想干点什么」。

---

## 这个插件跟别的「主动发言」插件差在哪

大多数主动发言插件的逻辑是：**到点了 → 生成一句话 → 发出去**。每一轮必然产出一句话。

这个插件的逻辑是：

```
到点了 → 冒出一个念头 → 自己判断有多想说（0~1）→ 加一点噪声 → 分层落地
```

分层规则：

| 想说程度 | 结果 |
|---|---|
| < 0.55 | **只想不说**，记一笔就完 |
| 0.55 ~ 0.80 | **小动作**：戳一下、点个赞、发张图、写进本子 |
| ≥ 0.80 | **真的说出来** |

另外还有一道闸门叫「社交成本」。半夜、刚说过话、上一条还没得到回应，都会抬高成本；
成本够高时，即使很想说也会**忍住**——而忍住的那句话不会消失，它沉进心事单。

**大部分轮次的结果是什么都不做。** 这不是失败，这就是它像人的原因：
一天到晚都在找话说的人，现实里不太存在。

---

## 三条附带机制

**心事单**：说不出口的念头进去。同一件事再次想起时张力升高（不是记两条），
按 7 天半衰期慢慢变淡，淡到 0.12 以下才真正忘掉。

**凌晨整理**：3–6 点之间做一次清算——张力打七折、太平的归档、情绪冲淡。
一天只做一次，不会反复折腾。

**被纠正后长记性**：消息里出现「不是」「你说错了」「我没说过」这类词时，
记一条教训进心事单，标记为 `lesson`，以后别再提这件事。

## 安装

**方式一：插件市场**

AstrBot WebUI → 插件市场 → 搜索「杂念系统」→ 一键安装。

**方式二：手动**

1. 把整个 `astrbot_plugin_idle_mind` 文件夹放进 AstrBot 的 `data/plugins/` 目录
2. 重启 AstrBot，或从 WebUI 插件管理页重载
3. 打开插件配置，**至少填一项** `private_targets` 或 `group_targets`
4. 保存即可，不需要重启

**零外部依赖。** 不需要装心情插件、记忆插件、表情插件。装好后它自己会想事情。

会话 ID 的格式是 `平台ID:会话类型:目标ID`，例如：

```json
private_targets: ["default:FriendMessage:123456"]
group_targets:   ["default:GroupMessage:987654"]
```

最省事的取法：给机器人发一条私聊，然后在 AstrBot 日志里看这条消息的
`unified_msg_origin` 字段，原样复制过来。

## 命令

| 命令 | 作用 |
|---|---|
| `/mind` | 看当前心情、心里挂着几件事、累计说了几次忍了几次 |
| `/mind now` | 立刻想一次（调试用，能看到它这一轮的判断） |
| `/mind clear` | 清空心事单（仅管理员） |
| `/worry 内容` | 手动往它心里塞一件事 |

模型也能用两个工具：`mind_note`（自己记一件事）、`mind_recall`（看看心里挂着什么）。

## 配置项说明

只挑几个容易踩坑的说，其余在配置页里都有提示。

**`mood_mode`** — 心情从哪来。

- `inline`（默认）：自己按聊天内容微调，随时间回落到基线。零依赖，推荐。
- `file`：读一个 JSON 文件里的 `libido` / `aggression`。如果你已经在用别的情绪插件，
  让它往文件里写这两个数就行——**注意这里只读一个固定格式的文件，不读它的数据库**，
  对方换存储方式也不影响这边。
- `none`：固定中性值。

**`daily_limit`** — 每天最多「真的做出几次动作」。纯思考不计入。
模型抽风时这个数字能救你的 API 额度。

**`context_file`** — 可选。指向一个纯文本文件，内容会作为「你记得的一些事」注入提示词。
装了长期记忆插件的话，让它定期导出一份纯文本到这儿即可。
**本插件不解析任何结构化格式**，这样对方怎么改都影响不到这里。

**`quiet_hours`** — 免打扰时段，格式 `起始-结束`，如 `1-7`。留空表示不限制。

## 数据文件

都在 `data/plugin_data/astrbot_plugin_idle_mind/` 下：

| 文件 | 内容 |
|---|---|
| `worries.jsonl` | 心事单，一行一件。**格式是公开的**，见下 |
| `state.json` | 自身状态（心情、计数、上次整理时间） |
| `mind.db` | 消息缓冲 + 笔记（SQLite） |
| `activity/activity-YYYY-MM-DD.jsonl` | 每天它想了什么、做了什么 |
| `journal.md` | 选择「写日记」出口时的产出 |

`worries.jsonl` 的格式约定（别的插件可以直接按这个读）：

```json
{"text": "欠他一顿饭", "tension": 0.62, "at": 1761900000.0, "kind": "hold"}
```

- `text` 内容，最多 80 字
- `tension` 张力 0~1
- `at` 最后一次被想起的时间戳
- `kind` `hold`（想说但忍住）/ `manual`（手动塞的）/ `lesson`（被纠正的教训）

配套插件 **思考系统**（`astrbot_plugin_self_task`）就是靠读这个文件把心事变成选题的。
两个插件之间**没有 import、没有共享代码**，只有这份文本格式的约定。

## 它和「思考系统」怎么配合

| | 杂念系统（本插件） | 思考系统 |
|---|---|---|
| 想什么 | 我现在想说什么 | 有没有什么事该办 |
| 出口 | 嘴 | 手 |
| 周期 | 20–60 分钟 | 60–180 分钟 |

两个都装：它心里挂着的事会变成「思考系统」的选题，形成
**想说没说的 → 想想能不能办 → 办完回来说** 的闭环。

只装一个：完全正常。两者互不为依赖。

## 设计说明与灵感来源

「念头 → 自评 → 分层落地」这套机制是本插件原创的实现，源自一个观察：
**人的表达欲不是恒定的，而是有阈值的**——同一句话，在半夜、在刚被冷落之后、
在心情好的时候，说出口的概率完全不同。把这件事拆成「意愿强度」和「社交成本」
两个独立变量，再用噪声打散，行为才有毛边，而不是每次都由模型给一个四平八稳的句子。

「心事」这个概念借自认知心理学里的 Zeigarnik 效应（未完成的任务更容易被记住），
并用半衰期衰减来模拟「时间冲淡」。

本插件不包含任何来自其他 AstrBot 插件的代码。消息缓冲、心事存储、情绪模型
全部为本插件自行实现，因为依赖别人的数据结构会带来静默失败——
对方升级一次，这边就读到空值，而用户看不到任何报错。

## 已知的边界

- **不会主动找人闲聊**，那是思考系统或别的插件的事。本插件只管「想不想说」。
- **没有长期记忆**。它记得的只有：心事单、今天干过什么、最近几十条消息。
  真正的长期记忆请交给专门的插件，用 `context_file` 接进来。
- **心事单上限 200 条**，超出时丢掉张力最低的。设计上不希望它变成一个待办清单。
- 半夜整理只在 3–6 点之间触发，如果服务器那个时段是关机状态，就永远不会整理。
  这不是 bug，是刻意不做「错过的整理补做」——补做会让衰减变得不可预测。
